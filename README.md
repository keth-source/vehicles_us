# Análise de Dados de Veículos

Este é um aplicativo web simples construído com Streamlit para explorar dados de veículos usados nos EUA.

## Funcionalidades
- Visualização interativa da distribuição de preços através de histogramas.
- Gráfico de dispersão entre odômetro e preço.

Dataset: `vehicles.csv`
